# SecureOps

SecureOps is an automated security analysis and developer guidance platform designed to help developers identify, analyze, and remediate security vulnerabilities in source code, dependencies, and web targets.

## Features

- GitHub repository security scanning
- Source code file upload scanning
- Website URL security scanning
- Static code analysis
- Dependency vulnerability detection
- Secret detection
- Severity classification
- Security score generation
- AI-driven remediation guidance
- Interactive security dashboard

## Tech Stack

- Frontend: Next.js
- Backend: Node.js
- Database: MongoDB
- Security Tools:
  - Semgrep
  - npm audit
  - Gitleaks

## Installation

### Clone repository

```bash
git clone https://github.com/Bhavanaa02/SecureOps
cd SecureOps
```

### Install dependencies

```bash
npm install
```

### Start application

```bash
npm run dev
```

### Open in browser

```bash
http://localhost:3000
```
